# apmlprojects.com

Website van APML Projects. Statische pagina, gehost op GitHub Pages.

- `index.html` – de landingspagina
- `bedankt.html` – pagina na het versturen van het contactformulier
- `favicon.svg` – APML-monogram
- `CNAME` – koppelt www.apmlprojects.com (apmlprojects.com wordt bij Squarespace doorgestuurd naar www)

Contactformulier loopt via FormSubmit (formsubmit.co) naar info@apmlprojects.com.
